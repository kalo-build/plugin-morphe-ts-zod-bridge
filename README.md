# plugin-morphe-ts-zod-bridge

Generates TypeScript converter functions that bridge between Zod schemas (wire format) and TypeScript types (application format). The bridge operates directly on the Morphe registry and applies deterministic casing transformations — no `.map` files or manual steps required.

See [ADR-001: Casing Bridge Architecture](../kalo-plugin-registry/docs/decisions/001-casing-bridge-architecture.md) for the full decision context.

## How It Works

Both `plugin-morphe-ts-types` and `plugin-morphe-zod-types` read the same Morphe registry and use the shared `go-util/strcase` library for field name derivation. This plugin does the same: for each model, structure, and entity, it generates a converter function that maps fields from source casing (e.g., `snake_case` for Zod) to target casing (e.g., `camelCase` for TS types).

Validation is delegated to `tsc` — the generated converters import the actual generated types, so any drift between plugins produces a compile error.

## Pipeline Position

Runs **in parallel** with both upstream plugins — all three read the Morphe registry independently:

```
Stage N: plugin-morphe-ts-types         (parallel)
         plugin-morphe-zod-types        (parallel)
         plugin-morphe-ts-zod-bridge    (parallel)
```

## Input

- Morphe registry (`KA:MO1:YAML1`)

## Output

- TypeScript converter files (`KA:MO1:TS_BRIDGE1`)

## Configuration

```yaml
"@kalo-build/plugin-morphe-ts-zod-bridge":
  sourceCasing: "snake"                        # Zod schema field casing
  targetCasing: "camel"                        # TS type field casing
  zodSchemasImportPath: "@/generated/schemas"  # Import path for Zod schemas
  tsTypesImportPath: "@/generated/types"       # Import path for TS types
```

## Example Output

Given a `Person` model with fields `FirstName`, `LastName`, `Email`:

```typescript
// Code generated by plugin-morphe-ts-zod-bridge. DO NOT EDIT.
import type { Person } from '@/generated/types/models/person';
import { personSchema } from '@/generated/schemas/models/person';
import { z } from 'zod';

export function convertPerson(
  source: z.infer<typeof personSchema>
): Person {
  return {
    firstName: source.first_name,
    lastName: source.last_name,
    email: source.email,
  };
}
```
